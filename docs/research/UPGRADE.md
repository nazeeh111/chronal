## Recommended bounded implementation

Implement one pure NumPy descriptive risk module using complete net-of-cost portfolio returns, with: downside deviation and Sortino at zero target, historical lower 5% return quantile, empirical tail mean and effective tail count, longest underwater run including unrecovered final runs, exposure/cash/concentration from ledger, and active return/tracking error on exactly paired benchmark paths. Display unavailable ratios as null with explanation. Name loss versus signed-return units explicitly. A zero-volatility benchmark makes beta unavailable, not zero. Annualized quantities use the registered sessions-per-year assumption. These analytics describe observed history and are not forecast risk or evidence of alpha.

Recommended checks: short samples, all-positive/all-zero returns, ties at tail boundary, monotonic rising NAV, a final unrecovered drawdown, nonmatching benchmark length, and hand-calculated net returns including initial allocation costs. Do not replace the existing selection criterion or inspect holdout to tune a strategy merely because more diagnostics become available.

Do not add heavy optimization dependencies or an LLM graph for breadth alone. Riskfolio is a useful expansion alternative; cvxportfolio is a serious execution/optimization model reference, not an accuracy badge. QuantStats/Empyrical are strong independent metric-definition references, but no local implementation equivalence was tested.
