Read these risk measures

Ulcer index is the root mean square of percentage drawdowns from the running peak. Longest underwater spell counts consecutive marked sessions below the prior peak, including an unrecovered endpoint. Historical tail mean averages the worst ceil(5% × sessions) session returns; a short sample can reduce this to one session. None estimates a future loss bound.

Recorded events in this session

Requested quantities use the target and opening NAV before this session's fills. Capacity is a daily-volume proxy. Cash-scaled quantity precedes any final cash clamp; filled quantity is the actual ledger. Expired remainder is requested minus filled, signed by side, and is not carried forward. Price concession plus commission measures recorded currency friction, not a counterfactual NAV loss. An absent intent does not establish why the strategy made no decision.

Full evaluated region / actual recorded requests

Execution finder

Each row is one eligible nonzero asset request at one attempted open. Partial or blocked means an exact nonzero remainder, including rounding residuals; inspect its recorded reasons. Filters combine within this region and strategy. Inspect session updates the linked chart, account, model and execution inspector; it does not refit or change the frozen candidate. Asset focus is shared with holdings, session request rows and fills. Outcome/reason filters apply only to this finder; session/side filters apply only to fills. Portfolio totals remain unchanged. Counts are attempts, not round-trip trades or a share-weighted fill rate.

Syntax and keyboard reference

Commands inspect this saved experiment. They do not execute code or orders.

  • / Focus command bar
  • strategy NAME Select a registered portfolio
  • view equity or view drawdown
  • goto performance|risk|interval|episodes|account|model|execution|finder|method|ledger|provenance
  • session YYYY-MM-DD Inspect a unique available UTC date; session #N selects a 1-based session (including intraday data)
  • range START END Compare two dates or #N session positions; reset restores the full interval
  • asset #N Focus the Nth asset across detail tables; asset clears focus. Portfolio totals stay unchanged.
  • fit #N Inspect a recorded refit and its first evaluated session
  • next-event / previous-event Jump to recorded event evidence
  • On the session slider, use arrow keys for adjacent sessions.
  • Escape Leave the command bar or close this help
  • find constrained finds partial or blocked requests across this region; find all resets finder filters.
  • The Commands button opens this searchable palette. Alt+↑/Alt+↓ recall up to 100 recent commands and restore your draft. History stays in this open report only; recalling does not execute.
