# Upstream ideas and license boundaries

Chronal's implementation is original code, released under MIT. It does not vendor or copy source from the investigated trading repositories, install their packages, or claim runtime integration with them. Its numerical learning and array operations use NumPy, which carries its own BSD license and notices in installed distributions. Python and development tools retain their own licenses.

The source-level investigation informed architecture and failure tests. Credits and pinned implementation links are in [RESEARCH.md](docs/RESEARCH.md), [SOURCES.json](docs/research/SOURCES.json), and the detailed research reports. Source snapshots were retained in the build workspace for inspection; they are not redistributed as MIT project source.

Particular boundaries: current vectorbt source includes Commons Clause restrictions; Freqtrade is GPL-3.0 and NautilusTrader is LGPL-3.0. Those licenses must be assessed before any future copying or distribution of adapted code. A future adapter would need its own dependency, license and runtime-verification work. Current compatibility is through ordinary documented CSV/JSON, not a tested upstream engine adapter.

The demo data is generated by Chronal and may be redistributed under the project license. No third-party market dataset, news archive, research paper text, private user material or model weight is bundled. Software licensing does not grant rights to market data, trademarks or provider services.

The original diagram assets were authored with the PaperBanana-derived Flowcraft workflow. No upstream inference code, example artwork, model weights or provider API was used or bundled. SVG masters and data-driven generating code are retained in docs/figures and tools/.
